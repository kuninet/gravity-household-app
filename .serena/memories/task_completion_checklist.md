# タスク完了時の実行項目

## 1. コード品質チェック
```bash
# 構文エラーチェック（手動）
# - JavaScriptファイルの構文確認
# - Vue.jsコンポーネントの構文確認
# - package.jsonの整合性確認
```

## 2. 機能テスト
```bash
# 開発サーバー起動テスト
npm run dev

# APIエンドポイントテスト
curl http://localhost:3000/api/health

# データベース接続テスト
# - SQLite3データベースファイルの存在確認
# - テーブル構造の確認
```

## 3. ビルドテスト
```bash
# フロントエンドビルド
cd client
npm run build

# ビルド結果の確認
npm run preview
```

## 4. データベース整合性チェック
```bash
# データベースファイルの確認
ls -la server/household.db*

# 必要に応じてデータベース再初期化
npm run seed
```

## 5. 依存関係の確認
```bash
# セキュリティ脆弱性チェック
npm audit

# 依存関係の更新確認
npm outdated
```

## 6. Git操作
```bash
# 変更内容の確認
git status
git diff

# ステージング
git add .

# コミット（日本語メッセージ）
git commit -m "機能追加: [具体的な変更内容]"

# プッシュ
git push
```

## 7. ドキュメント更新
- README.mdの更新（必要に応じて）
- APIドキュメントの更新（新しいエンドポイント追加時）
- コメントの追加・更新

## 8. 動作確認項目
- [ ] フロントエンドが正常に表示される
- [ ] APIが正常にレスポンスを返す
- [ ] データベース操作が正常に動作する
- [ ] エラーハンドリングが適切に動作する
- [ ] 既存機能に影響がない

## 注意事項
- 本プロジェクトには自動テストが設定されていないため、手動での動作確認が重要
- データベースの変更を行った場合は、必ずバックアップを取ること
- 新しい依存関係を追加した場合は、package.jsonの更新を確認すること
