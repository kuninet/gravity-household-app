# コードスタイルと規約

## 言語設定
- **思考プロセス・ログ**: 日本語で記述
- **ユーザーコミュニケーション**: 日本語で対応
- **コミットメッセージ**: 日本語で記述

## JavaScript/Vue.js スタイル

### ファイル命名規則
- Vueコンポーネント: PascalCase (例: `TransactionForm.vue`)
- JavaScriptファイル: camelCase (例: `api.js`, `utils.js`)
- ルートファイル: kebab-case (例: `fixed_costs.js`)

### コード規約
- **インデント**: 2スペース
- **セミコロン**: 使用しない（Vue.js標準）
- **クォート**: シングルクォート使用
- **関数定義**: アロー関数を優先
- **変数宣言**: `const` > `let` > `var`の順で優先

### Vue.js 固有の規約
- **Composition API**: `<script setup>`構文を使用
- **リアクティブ変数**: `ref()` と `reactive()` を適切に使い分け
- **コンポーネント名**: PascalCaseで命名
- **プロパティ**: camelCaseで定義

### API設計
- **RESTful**: REST原則に従ったAPI設計
- **エラーハンドリング**: try-catch文で適切にエラー処理
- **レスポンス形式**: JSON形式で統一

## データベース規約
- **テーブル名**: 複数形（例: `transactions`, `categories`）
- **カラム名**: snake_case（例: `fiscal_month`, `category_code`）
- **主キー**: `id`で統一（AUTO_INCREMENT）

## ファイル構成規約
- **コンポーネント**: 機能別にディレクトリ分割
- **API**: 単一ファイル（`api.js`）で管理
- **ユーティリティ**: 共通関数は`utils.js`に集約
- **ルート**: 機能別にファイル分割（`routes/`ディレクトリ）

## コメント規約
- **関数**: 複雑な処理には日本語コメントを追加
- **API**: エンドポイントの説明を記載
- **設定**: 設定値の意味を明記

## 例外処理
- **フロントエンド**: `console.error()`でエラーログ出力
- **バックエンド**: 適切なHTTPステータスコードを返却
- **データベース**: トランザクション処理を適切に実装
